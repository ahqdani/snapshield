🔐 SnapShield

Snapchat Security Auditor — privacy-first account checks

🔍 Username Breach Check

Opens LeakCheck so you can check a Snapchat username on the provider's site. Your username is never sent through an untrusted CORS proxy.

📋 Leaked Credential Search (COMB)

Opens ProxyNova's COMB tool for a provider-hosted search. SnapShield does not transmit the search term or expose leaked passwords on this page.

🔑 Password Leak Check

Your password is hashed in-browser. Only 5 characters of the SHA-1 hash are sent — the full password never leaves your device. Uses Have I Been Pwned's k-anonymity API.

🛡 Security Recommendations
✅
Enable 2FA — Go to Snapchat Settings → Two-Factor Authentication. Use an authenticator app (not SMS).
✅
Unique password — Never reuse your Snapchat password on any other site. Use a password manager.
✅
Audit sessions — Snapchat Settings → Session Management. Remove unknown devices.
✅
Verify linked email & phone — Make sure both belong to you and haven't been changed.
✅
Review connected apps — Settings → Connected Apps. Remove anything unused.
